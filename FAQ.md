# **Notable Questions**
## **How does the program work?**
When launched, the program will encrypt files from specific directories (read the code to see which directories are listed) just like a ransomware, and it will ask for a decryption key, and the user will have 3 chances, if exhausted, the program will delete the existing account and create a new one with a password, which makes the program worse than a typical ransomware.
More details: Explain.md
## **Can you tell me the password you added?**
Of course not, but since the program is open source, you can find it in the source code.

DON'T OPEN IT ON YOUR MAIN PC OR SOMETHING DANGEROUS MIGHT HAPPEN, instead, try moving it to an isolated virtual machine or a sandbox, since I won't recommend using it on a real PC, even if it is an alt PC or has dualboot

- As for Android, it will be more complicated since the code is based on C++ and Java works best for Android apps, but of course you can try porting it.
